# Les sujets du projet IA

Choisissez **un** sujet. Chaque fiche dit pour qui vous travaillez, ce que l'application reçoit et doit rendre, les règles à respecter, les cas pièges que votre jeu d'évaluation doit contenir, et à quoi on reconnaît une application réussie. Les données d'exemple sont dans le dossier du sujet : partez d'elles pour écrire `prompt.txt` et `cas.json`.

| N° | Sujet | Organisation (fictive) | Sortie | Difficulté |
|---|---|---|---|---|
| 1 | [Assistant de FAQ](1-faq-mediatheque/) | Médiathèque Les Tilleuls | réponse courte + article cité | ★★☆ |
| 2 | [Tri des demandes de support](2-tri-support/) | Atelier Numérique du Pilat | JSON | ★★☆ |
| 3 | [Compte rendu → actions](3-compte-rendu/) | Basket Club du Gier | JSON | ★★★ |
| 4 | [Réponse aux avis clients](4-avis-clients/) | Le Fournil des Monts | texte cadré | ★☆☆ |
| 5 | [Fiches produit](5-fiches-produit/) | Cycles Forez | texte structuré | ★☆☆ |
| 6 | [Sujet libre, lié au stage](6-sujet-libre/) | votre entreprise (données fictives) | à définir | à valider |

★☆☆ : la difficulté est dans la consigne. ★★★ : elle est aussi dans le traitement (dates, extraction fiable).

Toutes les organisations, personnes et données de ce dossier sont **inventées**. Les numéros de téléphone utilisent la plage réservée à la fiction.
